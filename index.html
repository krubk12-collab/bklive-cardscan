3 ขั้นตอน: สร้างข้อสอบ → พิมพ์การ์ด → สอบเลย

1️⃣ สร้างแบบทดสอบ — แท็บ 📝 คำถาม
คัดลอกข้อสอบจาก Word มาวางในช่อง "นำเข้าข้อสอบ" รูปแบบ
1. คำถาม… / ก. … ข. … ค. … ง. … / เฉลย ข
กด 📥 แปลง & นำเข้า → ตั้งชื่อชุด เสร็จ! (หรือกด ➕ ชุดใหม่ แล้วพิมพ์ทีละข้อก็ได้)
2️⃣ พิมพ์การ์ด — แท็บ 🖨️ การ์ด (ทำครั้งเดียว ใช้ซ้ำได้ทุกการสอบ)
กด โหลดห้อง → เลือกห้อง → ดึงรายชื่อ (ติ๊กเลือกบางคนได้ แล้วบันทึกเป็นกลุ่มไว้ใช้ซ้ำ) → สร้างการ์ด → 🖨️ พิมพ์/PDF → แจกการ์ดตามเลขที่นักเรียน
3️⃣ สอบ — แท็บ 📷 สอบ(การ์ด)
เช็คแถบบนว่าเลือก 📚 ชุดข้อสอบ และ 👥 กลุ่ม ถูกต้อง → เลือกโหมด ก่อนเรียน/หลังเรียน → กด ▶️ เปิดกล้อง
นักเรียนชูการ์ด หันตัวอักษรคำตอบ (ก/ข/ค/ง) ขึ้นด้านบน → กวาดกล้องให้เห็นการ์ด ช่องนักเรียนจะเขียวทีละคน → ครบแล้วกด ถัดไป ▶ จนจบ → กด ✅ จบ/บันทึกผล
💡 เคล็ดลับ: เปิด 📺 จอใหญ่ บนคอม/โปรเจกเตอร์ (เลือกครูคนเดียวกัน) เด็กจะเห็นโจทย์+ใครตอบแล้วแบบสด · ดูคะแนนพัฒนาการและ 📈 ความยาก-ง่ายรายข้อ ได้ที่แท็บ 📊 ผลสอบ · ข้อสอบ/กลุ่มซิงค์ข้ามเครื่องอัตโนมัติ ☁️ แค่เลือกชื่อครูเดียวกัน
